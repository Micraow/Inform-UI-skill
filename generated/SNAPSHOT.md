# Generated contract snapshot

The static module and View contracts were generated from the same bundled runtime listed in runtime-lock.json. snapshot-status.json records file hashes and generation provenance. Keep these files, the runtime and the default profiles together; after changing runtime bytes, regenerate contracts before authoring. For small selections, scripts/inform-answer.mjs prompt generates the exact current contract without loading all composed Views.

JSON Schema and prompt do not claim full semantic equivalence: runtime-only rules are annotated, incompletely described domain rules are marked, and native UTF-16 string-length behavior is disclosed.
