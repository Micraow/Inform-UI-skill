## 失败归因与保留观察

本轮首稿未触发作者错误、Skill 合同错误或阻断性库错误。此前常规示例 CI 的两处失败属于验收脚本：

1. 测验答题后正确选项增加“参考答案”辅助文字，原 exact `40%` 定位不再匹配；改为核对所有选项禁用且原选择保留。
2. 赛程筛选控件实际名称是“比赛日期”，原脚本使用 exact “日期”；修正定位文字。

以上只改变验收脚本，没有修改文档根输入、示例业务数据、冻结首稿或核心库。

人工视觉观察中有两个不影响本轮功能通过的实现打磨项，不能隐藏为“完全无问题”：

- 答题后的可见 live status 重复显示了反馈区已经显示的解释。后续核心库可保持屏幕阅读器播报并减少视觉重复。
- 手机积分榜保留全部列，局部横向滚动。初始截屏只显示左侧列，横向可滚动的提示较弱；手机长比赛选项也会被原生 select 截短，但下方详情保留完整时间。

本实验支持“一个全新作者仅靠此根 Skill 能首次生成这类体育＋学习组合页面”，不等于所有作者、所有提示词或全部 46 种节点都已经盲测。成绩只在本轮页面内存在，答案是公开文档数据；没有实时赛事、远程批改或保存成绩能力。

原 HTML 末尾“尚未实际打开验证”保留作者首次交付时的真实声明；本报告是之后独立验收记录。
