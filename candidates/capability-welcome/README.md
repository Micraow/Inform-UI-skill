## Authoring contract

Resolved input needs `label`, `items` (at most20) and `actions` (at most30). IDs are unique within each collection. Every item references an action by `actionId`, independently of visible label and list order. Missing mappings stay visible and disabled. Empty arrays remain honest empty content.

The finite action union is prompt with supplied `query`, URL with safe `url`, opaque capability with explicit `available:true`, or voice. Voice is unavailable in this presentation even if its supplied availability is true. Unknown/false capability availability, node/item/action disabled, native fieldset, control `aria-disabled`, hidden/inert and capture cancellation are honored. There is no arbitrary dispatcher payload.

`iui:capability-welcome` carries frozen `{id,itemId,actionId,intent,campaignId?,query?|url?|capability?}`. It bubbles, is cancelable and is non-composed. Intent is `submit-prompt`, `open-url` or `open-capability`. The supplied receipt adapter records and cancels it. Acceptance changes only the local receipt; it does not execute navigation, a service, telemetry, an account change or a permission request.

Icons use an explicitly supplied safe image source and decorative empty alt. Failure displays the supplied fallback symbol, and retired resources release their sources. No icon or favicon is looked up. External icon sources can load through the shared image reader; this fixture uses inline artwork only. Long visible labels retain their accessible names.

Pending/failed states may omit data arrays. Failure text is literal or the whole view is hidden. The project-local visible Reset button clears the receipt. Canceled form reset preserves it; a pending reset blocks new action requests. Replacement/disposal supersede old queued reset work.
