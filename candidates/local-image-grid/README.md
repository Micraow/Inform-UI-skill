# Original finite image-grid draft

The three colored PNGs are generated entirely by this project's local JavaScript fixture helper. A supplied ID, bounded alternative text and optional caption belong to each image. There is no image search or generated media.

`attachGridReceipt(host, output)` cancels the frozen local `{id,index}` image intent and writes plain text outside the mount host. It does not open a gallery or navigate. Six positive/fifteen negative documents cover the finite0..24 image API,1..4 columns, fit and supplied data validation.

This newly authored grid contract is intentionally distinguished from the unavailable historical ImageGrid API. Exact runtime validation, decoded images, responsive geometry and native pixels await their own fixed input.
