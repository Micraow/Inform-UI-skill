# Original finite learning-media examples

Authoring checkpoint for `learning-image-choice-card`, `learning-image-label-card` and `learning-audio-label-card`. No restored-runtime acceptance or new asset lock is claimed yet. All pictures and the short electronic tone are generated by the included independent JavaScript; no photo, private capture, voice recording, speech model or external SDK is bundled.

Generate the exact fixture and run host-only checks:

```sh
node candidates/restored-learning-media/generate-fixture.mjs
node --test tests/restored-learning-media.test.mjs
```

The shared fields are label, prompt, optional explanation and literal boolean disabled. Choice has2–8 supplied options with unique IDs and a supplied answerId referencing one option. Label cards accept1–12 nonblank answers up to200 characters; matching trims outer whitespace and remains case-sensitive. Answers are ordinary public teaching material, not secret exam keys.

Images need alternative text and supplied safe HTTP(S) or base64 raster content. Audio needs an explicit transcript and supplied safe HTTP(S) or nonempty base64 WAV/MPEG/OGG/MP4/WebM content. There is no recording, speech recognition, search or generation API. Audio host checks follow the recovered contract, including its bounded hostname and loopback restrictions. Remote media stays unloaded until the user explicitly enables it. External-media examples are validation cases; the primary executable example is fully inline.

Practice check, reveal and retry are local state. Disabled applies to practice controls and new external-media activation, not to a blanket promise that native audio playback or transcript disclosure is disabled. The restored runtime must retain no autoplay and preload=none, own its active media resource, and use the current shared lifecycle scaffolding. Real media decoding, audible playback and visual fidelity require separate browser evidence.

Six positive and16 negative documents prepare the complete family. PNG pixels and the WAV container are checked directly, without treating file structure as browser playback acceptance.
