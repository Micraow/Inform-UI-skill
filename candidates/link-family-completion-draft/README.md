# Original finite link-family fixture data

This neutral draft prepares three fictional HTTPS links on `example.test`, original passive Text/Box content, a24px inline icon and a128×96 inline image. The images are produced by the existing original PNG generator, not copied from a site. Titles, snippets and source labels are explicitly supplied.

These are data and intended scenarios, not a final schema or accepted runtime API. After the library writer fixes the three contracts, map them explicitly and run the actual validators and local DOM/compiler consumers. Opening/copying remains a cancelable host request; these fixture tests do not navigate, fetch previews, access a clipboard or derive favicon URLs. They do not establish native hover/geometry or canonical coverage.

```sh
node --test tests/link-family-completion-draft.test.mjs
```
