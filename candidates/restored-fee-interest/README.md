# Original supplied fee and interest draft

This synthetic fixture supplies independent totals and display labels. The 900 total is deliberately unrelated to the five row labels. Never parse the labels or add them to derive totals, refunds, currency conversions or account balances.

`totalPaid` is a finite supplied number or null. Zero is a real observation; null stays unreported. `totalPaidLabel` and each row's `amountLabel`, `dateLabel`, `categoryLabel` and `accountDetail` are explicit display copy. A free-form date label is not a machine date. Supplied `amountTone` is presentation, not inferred transaction meaning.

The first range has five rows to exercise the bounded local expansion. Other ranges separate true zero and unknown total. The only logo is an independently generated inline color square reused from this Skill's learning fixture. No logo, private screenshot, bank data or provider request is imported.

Range selection, expansion, masking and any original local intent remain reading controls. No account mutation, payment, bank connection or persistence is part of this example.

Five positive and twelve negative authoring documents are prepared. Runtime, standalone, CDN and native acceptance are pending the single exact restored source/build.
