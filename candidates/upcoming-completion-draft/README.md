# Upcoming flow supply draft

Original incoming/outgoing teaching records, each with a separate top item. Incoming ordinary items expand from two to four; outgoing has a shorter alternate list and must not expand. A pure fixture oracle makes replacement, rather than concatenation, explicit.

Opaque amount/date labels include true zero, a supplied negative refund notation and null unknowns. No sum, calendar calculation, provider request or account data is involved. The fixture's flow fields await the author's exact schema mapping. Tests here check data expectations only; Upcoming remains partial until a fixed runtime consumer and functional acceptance.
